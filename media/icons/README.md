# Iconos de áreas HMV

Sistema raster conceptual basado en la plantilla UI/UX. Cada icono es un PNG cuadrado con canal alfa real fuera de su disco circular.

## Receta común

- símbolo único y centrado;
- disco circular pálido;
- formas redondeadas y peso visual uniforme;
- sin texto, sombras, 3D ni watermark;
- lectura objetivo a 48 px;
- transparencia real fuera del disco.

## Prompt — Green Solutions

~~~text
Use case: logo-brand
Asset type: individual website area icon — Green Solutions
Input images: Image 1 is the UI/UX style reference; Image 2 is the brand palette and shape-language reference
Primary request: create one original icon representing sustainable technology solutions for organizations
Subject: one elegant upright leaf paired with one compact gear, interlocked clearly but without clutter
Style/medium: flat vector-like UI icon, geometric organic shapes, rounded consistent bold strokes, crisp edges
Composition/framing: single centered symbol inside one pale circular disk, generous transparent padding outside the disk, square canvas
Color palette: leaf green #2E8B57 and forest #073B2A on a very pale green disk #E9F5E8; flat colors only
Background: genuinely transparent outside the circular disk
Constraints: exactly one icon; no text; no letters; no extra badge; no shadow; no gradient; no 3D; no watermark; readable at 48 px
Avoid: realistic leaf texture, multiple gears, recycling arrows, generic clip art, thin details
~~~
