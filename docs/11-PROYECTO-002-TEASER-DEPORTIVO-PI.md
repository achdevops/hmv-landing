# Proyecto 002 — teaser deportivo protegido por PI

## 1. Regla principal

La web pública solo comunica la existencia de una exploración vinculada al reconocimiento deportivo. No explica el mecanismo, participantes, flujo, tecnología, monetización, diferenciadores, mercados, roadmap técnico ni estrategia de patente.

La opción más segura es no publicar hasta que un profesional de PI apruebe el texto. El teaser es una alternativa de comunicación, no una obligación.

## 2. Copy público permitido

Resumen: Estamos investigando una experiencia digital vinculada al reconocimiento deportivo. Debido a que el concepto se encuentra en proceso de protección de propiedad intelectual, compartiremos más información cuando sea oportuno.

Aviso: No se recibirán propuestas confidenciales a través del formulario público.

## 3. Información prohibida

- nombre real del producto si no fue protegido;
- descripción de cómo funciona;
- diagramas, pantallas o journeys;
- deporte, liga, evento o usuario específico si revela estrategia;
- token, reward, scoring o settlement design;
- algoritmos;
- arquitectura;
- datasets;
- modelo comercial;
- validaciones o conversaciones;
- competidores y diferenciación;
- claims “patent pending” sin confirmación formal por jurisdicción;
- archivos descargables;
- repositorios;
- metadata/alt/OG que revele más que el texto.

## 4. Implementación

Opción A, recomendada hasta revisión legal:

- tarjeta no enlazada;
- no hay URL;
- no aparece en sitemap;
- no hay JSON-LD;
- no hay imagen específica.

Opción B, después de aprobación:

- página teaser con noindex inicial;
- copy exacto aprobado;
- imagen abstracta genérica;
- formulario con categoría general;
- revisión del HTML, metadata, source maps y repositorio.

Nunca guardar contenido secreto en el repositorio público con draft o CSS oculto. Git conserva historial.

## 5. Revisión antes de publicar

- [ ] Profesional de PI revisó el texto.
- [ ] Se confirmó la expresión legal permitida.
- [ ] Dominio, nombre y visual no afectan registro futuro.
- [ ] No hay detalles en filename, alt, metadata o commits.
- [ ] El formulario advierte no enviar información confidencial.
- [ ] La persona responsable firmó aprobación de publicación.

## 6. Criterios de aceptación

- un visitante solo comprende que existe una exploración deportiva;
- no puede reconstruir la solución;
- no hay material técnico en el bundle ni Git;
- el teaser puede retirarse sin romper navegación;
- el proyecto costero sigue siendo el único flagship público.
